# SinterAppleEvents
Swift package for AppleEvent support

This package is used as a dependency of the SinterPixelsSwim package, a swift package you can include in your swift code to drive the scriptable SinterPixels app from swift, effectively using swift as a scripting language.  The SinterPixelsSwim package is here:

    https://github.com/olofhellman/SinterPixelsSwim
    
There is example code on how to use the SinterPixelsSwim package in this example project:

    https://github.com/olofhellman/SinterPixelsSwimExample
